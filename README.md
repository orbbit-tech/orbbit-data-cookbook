# Orbbit Data Cookbook

Features you can add to your product with [Orbbit Data](https://www.orbbit.co/data/developers), grouped by data set.

Each example is a TypeScript function you copy into your own code, an optional React component that shows the result, and a one-page Next.js demo. The function has no dependencies, so it works in any server, scheduled job or AI agent tool.

## Examples

- [Food Commodity Prices](./examples/food-commodity-prices): USDA market prices for dairy, chicken and other food commodities.
  - [market-price-benchmark](./examples/food-commodity-prices/market-price-benchmark): show how a customer's purchase price moved against the USDA market over 12 months.

## Before you start

1. Sign up at [data.orbbit.co](https://data.orbbit.co). Every new account gets $5 of starting balance.
2. Copy your **Default** API key from **API Keys**.
3. Call the API from your server only, so the key never reaches a browser.

Docs: [docs.orbbit.co](https://docs.orbbit.co). Using a coding agent? See [AGENTS.md](./AGENTS.md).
