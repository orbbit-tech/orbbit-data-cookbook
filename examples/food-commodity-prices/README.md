# Food Commodity Prices

USDA market prices for dairy, chicken and other food commodities, by region and date. See the [data set](https://www.orbbit.co/data/developers/data-directory) and the [docs](https://docs.orbbit.co/market-data/commodities).

Each folder is one feature you can add to your product: a function to copy, an optional React component, and a one-page demo.

- [market-benchmark](./market-benchmark): show how a customer's purchase price moved against the USDA market over 12 months.
