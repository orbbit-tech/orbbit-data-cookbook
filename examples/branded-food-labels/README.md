# Branded Food Labels

Ingredients and nutrition for US packaged foods, as each brand reports its label to USDA, searchable by name, brand, category, barcode or ingredient. See the [data set](https://www.orbbit.co/data/developers/data-directory) and the [docs](https://docs.orbbit.co/industry-data/cpg/branded-food).

Each folder is one feature you can add to your product: a function to copy, an optional React component, and a one-page demo.

- [competitor-product-ingredients](./competitor-product-ingredients): show the closest competing products on the shelf, and which ingredients both use, only theirs uses, and only yours uses.
